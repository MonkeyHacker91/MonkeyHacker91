# Vinicius Nascimento

Infra e segurança em servidor de hospedagem — shared, VPS, WHM/cPanel, painéis.

Trabalho no que acontece depois que o site já está no ar: processo web fora do lugar, persistência, abuso de SSH, arquivo plantado no `public_html`. Kernel quando dá, agente no host quando precisa, perímetro quando o IP já mostrou a cara.

### Em que mexo

- Hospedagem e painéis (WHM, cPanel, Enhance, LiteSpeed)
- Linux, eBPF, firewall, automação de frota
- PHP e Node em produção, Redis, filas, Docker
- APIs e painéis internos (billing, provisionamento, ops)

### Stack

`Linux` · `eBPF` · `nftables` · `Node` · `Bun` · `PHP` · `React` · `Redis` · `Docker`
